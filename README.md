# Mehrshad Eskandarpour — Portfolio

Production-ready static portfolio for GitHub Pages / `mehrshadesk.ir`.

## Deploy
Upload the full contents of this folder to the root of the `main` branch of:
`MehrshadEsk/Mehrshadesk.github.io`

GitHub Pages will serve the custom domain from `CNAME`.

## Visual modes
- Obsidian Signal — default
- Deep Cobalt
- Ivory Editorial
- Graphite Orchid

The selected mode is stored in the browser with `localStorage`.

## Controls
- `T` — open visual theme selector
- `Cmd/Ctrl + K` — quick navigation

## Main files
- `index.html` — page content / SEO / structure
- `styles.css` — responsive design system and visual themes
- `script.js` — interactions, theme system, filters, motion
- `404.html` — custom GitHub Pages 404
- `CNAME` — custom domain
- `robots.txt` / `sitemap.xml` — basic SEO
- `manifest.webmanifest` — install metadata
- `assets/` — favicon and social preview assets
